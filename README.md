# 🚀 Portfólio — Michel Deziderio

Portfólio profissional desenvolvido para apresentar minha trajetória como Senior Software Engineer, alguns projetos, experiências, tecnologias, artigos e formações.

O objetivo deste projeto é centralizar minha presença profissional em uma interface moderna, responsiva e performática, destacando minha atuação com Angular, TypeScript, arquitetura Front-End, micro-frontends, Node.js, NestJS e desenvolvimento de produtos digitais.

## ✨ Sobre o projeto

Este portfólio foi criado com foco em:

- Apresentar minha experiência profissional de forma clara e objetiva.
- Destacar tecnologias utilizadas em projetos reais.
- Exibir projetos pessoais, estudos e produtos em desenvolvimento.
- Organizar artigos técnicos publicados.
- Facilitar o contato com recrutadores, empresas e outros desenvolvedores.
- Ter uma interface moderna, responsiva e com boa experiência de navegação.

## 🧑‍💻 Sobre mim

Sou Senior Software Engineer com experiência em aplicações corporativas, arquitetura escalável, micro-frontends, design systems, integração com APIs, autenticação, dashboards, produtos SaaS e aplicações web modernas.

Atuo principalmente com Angular, TypeScript, RxJS, Node.js, NestJS, React e tecnologias relacionadas ao ecossistema Front-End e Full Stack.

Também sou instrutor de cursos, compartilhando conhecimento sobre desenvolvimento Front-End, Angular, boas práticas e construção de aplicações modernas para o mercado real.
